# 開発計画書

このドキュメントは、本プラグインの今後の開発計画を管理するものです。

## 機能追加計画

### 1. 閲覧者コメント機能の追加

**目的**:
各語彙情報に対して、複数の架空の閲覧者からのコメントを自動生成・表示する機能を追加する。これにより、辞典の世界観に深みを与え、多角的な視点からの情報を提示することで、読み物としての魅力を高める。

**主要な実装項目**:
- **コメントデータモデルの定義**:
    - `CommentEntry.ts`: コメント一件分のデータ構造（コメンテーター名、コメント本文、タイムスタンプ等）を定義する。
- **語彙情報モデルの拡張**:
    - `lexicalEntry.ts`: `CommentEntry`の配列を保持する`comments`プロパティを追加する。
- **AI生成ロジックの更新**:
    - `geminiService.ts`: 単語情報生成時に、2〜3件の閲覧者コメントと、そのコメンテーターのペルソナを同時に生成するようプロンプトを更新する。
    - `LexicalEntry.ts`: JSONスキーマを更新し、AIが正しい構造でコメントを返却できるようにする。
- **表示フォーマッターの更新**:
    - `lexicalEntryFormatter.ts`: 生成されたコメント情報をMarkdown形式で表示する処理を追加する。

## 開発計画：語彙情報への「解説」項目の追加

単語の意味だけでは理解が難しい背景や文脈を補足するため、語彙情報に「解説」項目を追加します。

### 目的
- **情報の充実**: ユーザーが単語をより深く理解できるよう、補足的な解説情報を提供する。
- **AI生成品質の向上**: AIが生成する情報の表現力を高め、よりリッチな辞典コンテンツを作成する。

### 実装計画

1.  **モデルの更新 (`src/models/lexicalEntry.ts`):**
    -   `LexicalEntry` クラスに `explanation?: string;` プロパティを追加します。
    -   `getJSONSchema`, `fromJSON`, コンストラクタを更新し、新しいプロパティに対応します。

2.  **AIサービスの更新 (`src/services/geminiService.ts`):**
    -   `getLexicalEntry` のプロンプトを修正し、AIが「解説」を生成するように指示します。

3.  **フォーマッターの更新 (`src/formatters/lexicalEntryFormatter.ts`):**
    -   `toMarkdown` メソッドを更新し、`explanation` が存在する場合にその内容を整形して出力するようにします。

4.  **ドキュメント更新**:
    -   `docs/AI語彙情報生成仕様書.md` と `docs/プラグイン仕様書.md` に変更内容を反映します。

## 開発計画：チャットによる新規単語登録

ユーザーがチャットを通じて新規単語の登録を依頼できるように、AIのFunction Callingに新しいツールを追加します。

### 目的
- **対話的な辞典構築**: チャットでの会話の流れで、シームレスに新しい単語を辞典に追加できるようにする。

### 実装計画

1.  **`DictionaryProvider`の拡張**:
    -   `DictionaryProvider` インターフェースに、新しい単語ファイル（空ファイル）を作成する `createWord(word: string): Promise<{ success: boolean; message: string }>` メソッドを追加します。
    -   `ObsidianDictionaryProvider` に上記メソッドを実装します。ファイルが既に存在する場合のエラーハンドリングも行います。

2.  **`geminiService`へのツール追加**:
    -   `geminiService.ts` の `tools` 配列に、`createWordEntry` という名前の新しい関数宣言を追加します。このツールは `word` を引数に取ります。
    -   `functionHandlers` に `createWordEntry` のハンドラを追加し、内部で `dictionaryProvider.createWord` を呼び出すようにします。

3.  **AIプロンプトの更新**:
    -   `geminiService.ts` の `generateChatResponse` 内のシステムプロンプトを更新し、AIが新しい単語を登録できることを示唆する指示を追加します。（例：「ユーザーの依頼に応じて、`createWordEntry`ツールを使って新しい単語を辞典に登録することもできます。」）

4.  **ドキュメント更新**:
    -   `docs/AIチャット仕様書.md` に、新しいツール `createWordEntry` の仕様を追記します。
