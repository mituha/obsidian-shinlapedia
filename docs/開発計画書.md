## 開発計画：コンテキスト取得処理の分離

現在、AIとの通信を行う `geminiService.ts` やUI層である `ChatView.ts` が、ObsidianのAPI (`app.vault`など) に直接アクセスしており、責務が密結合しています。
これを解消するため、Obsidian環境に依存する処理を独立したファイルに分離するリファクタリングを行います。

### 目的

- **責務の分離**: AIサービスのロジックとObsidianのデータ操作ロジックを分離する。
- **テスト容易性の向上**: `geminiService` をObsidian環境なしで単体テストできるようにする。
- **保守性の向上**: コードの見通しを良くし、将来の機能追加や変更を容易にする。

### リファクタリング計画

#### Step 1: データプロバイダーのインターフェース定義

まず、Obsidianに依存するデータ操作の振る舞いを抽象化したインターフェースを定義します。

- **ファイル**: `src/providers/DictionaryProvider.ts` (新規作成)

```typescript
// src/providers/DictionaryProvider.ts
export interface DictionaryProvider {
    /**
     * 辞典に登録されているすべての単語の一覧を取得します。
     */
    getWordList(): Promise<string[]>;

    /**
     * 指定された単語の詳細な説明（ファイルの内容）を取得します。
     * @param word 内容を取得したい単語名
     * @returns ファイルの内容。見つからない場合はnullを返す。
     */
    getWordDetail(word: string): Promise<string | null>;

    /**
     * 現在アクティブなエディタのファイル内容を取得します。
     * @returns アクティブなファイルの内容。アクティブなファイルがない場合はnullを返す。
     */
    getActiveFileContent(): Promise<string | null>;
}
```

#### Step 2: インターフェースの具象クラス作成

次に、上記インターフェースを実装し、実際のObsidian APIを呼び出すクラスを作成します。

- **ファイル**: `src/providers/ObsidianDictionaryProvider.ts` (新規作成)

```typescript
// src/providers/ObsidianDictionaryProvider.ts
import { App, TFile } from 'obsidian';
import { DictionaryProvider } from './DictionaryProvider';
import { ShinLapediaPluginSettings } from '../shinLapediaSettings';

export class ObsidianDictionaryProvider implements DictionaryProvider {
    private app: App;
    private settings: ShinLapediaPluginSettings;

    constructor(app: App, settings: ShinLapediaPluginSettings) {
        this.app = app;
        this.settings = settings;
    }

    async getWordList(): Promise<string[]> {
        if (!this.settings.bookFolder) {
            return [];
        }
        const folderPath = this.settings.bookFolder;
        const files = this.app.vault.getMarkdownFiles();
        return files
            .filter(file => file.path.startsWith(folderPath + '/'))
            .map(file => file.basename);
    }

    async getWordDetail(word: string): Promise<string | null> {
        if (!this.settings.bookFolder) {
            return null;
        }
        const filePath = `${this.settings.bookFolder}/${word}.md`;
        const file = this.app.vault.getAbstractFileByPath(filePath);
        if (file instanceof TFile) {
            return this.app.vault.read(file);
        }
        return null;
    }

    async getActiveFileContent(): Promise<string | null> {
        const activeFile = this.app.workspace.getActiveFile();
        if (activeFile) {
            return this.app.vault.read(activeFile);
        }
        return null;
    }
}
```

`geminiService.ts` が `DictionaryProvider` インターフェースに依存するように変更します。Obsidianの `app` への直接参照をなくします。

- **変更対象**: `src/services/geminiService.ts`
- **修正内容**:
