# AIチャット仕様書

このドキュメントは、`geminiService.ts` の `generateChatResponse` 関数におけるAIの動作、特にプロンプト、Function Calling、およびコンテキスト利用に関する仕様を定義します。

## 概要

この機能は、ユーザーがサイドバーのチャットビューを通じてAI（編纂者）と対話できるようにするものです。AIは現在の編集中のファイル内容をコンテキストとして理解し、Function Callingを利用して辞典内の情報にアクセスしたり、新しい単語を登録したりしながら、自然な対話を行います。

## 実装

- **関数**: `generateChatResponse(userInput: string): Promise<string>`
- **ファイル**: `src/services/geminiService.ts`, `src/ui/ChatView.ts`
- **使用モデル**: `gemini-1.5-flash-latest`

対話のベースとなるシステムプロンプトです。

```plaintext
あなたは博識な辞典の編纂者です。ユーザーと対話してください。
必要に応じて単語の登録状況を確認し、既存の単語の意味に沿うように回答してください。
未登録、および既知の単語には[[単語]]の形でリンクを作成してください。
ユーザーの依頼に応じて、`createWordEntry`ツールを使って新しい単語を辞典に登録することもできます。
```

## Function Calling

AIは対話中に以下のツール（関数）を呼び出すことで、Obsidian内の情報にアクセスできます。

### 利用可能なツール

1.  **`getWordList()`**
    -   **説明**: 辞典に登録されているすべての単語の一覧を取得します。
    -   **引数**: なし
    -   **戻り値**: `{ words: string[] }` - 単語名の配列。

2.  **`getWordDetail(word: string)`**
    -   **説明**: 指定された単語の詳細な説明（Markdownファイルの内容）を取得します。
    -   **引数**:
        -   `word` (string): 内容を取得したい単語名。
    -   **戻り値**: `string` - ファイルの内容。見つからない場合はその旨を伝えるメッセージ。

3.  **`createWordEntry(word: string)`**
    -   **説明**: 新しい単語を辞典に登録します（空のファイルを作成します）。ファイル作成後、内容は別の仕組みで自動生成されます。
    -   **引数**:
        -   `word` (string): 登録する新しい単語名。
    -   **戻り値**: `{ success: boolean; message: string }` - 処理の成功有無とメッセージ。
