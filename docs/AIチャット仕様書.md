# AIチャット仕様書

このドキュメントは、`geminiService.ts` の `generateChatResponse` 関数におけるAIの動作、特にプロンプト、Function Calling、およびコンテキスト利用に関する仕様を定義します。

## 概要

この機能は、ユーザーがサイドバーのチャットビューを通じてAI（編纂者）と対話できるようにするものです。AIは現在の編集中のファイル内容をコンテキストとして理解し、Function Callingを利用して辞典内の情報にアクセスしながら、自然な対話を行います。

## 実装

- **関数**: `generateChatResponse(userInput: string, context: string): Promise<string>`
- **ファイル**: `src/services/geminiService.ts`, `src/ui/ChatView.ts`
- **使用モデル**: `gemini-1.5-flash-latest`

## プロンプト設計

### 基本プロンプト

対話のベースとなるシステムプロンプトです。

```plaintext
あなたは博識な辞典の編纂者です。ユーザーと対話してください。
必要に応じて単語の登録状況を確認し、既存の単語の意味に沿うように回答してください。
未登録、および既知の単語には[[単語]]の形でリンクを作成してください。
```

### オプション指示（ペルソナ設定）

プラグイン設定に応じて、AIのペルソナが動的に設定されます。

- **編纂者名 (`authorName`)**:
  - `あなたは辞典の編纂者「{authorName}」です。`
- **編纂者の説明 (`authorDescription`)**:
  - `あなたの設定: {authorDescription}。`
  - `この設定になりきって、ユーザーと対話してください。`
- **辞典のタイトル (`bookTitle`)**:
  - `あなたは辞典「{bookTitle}」を編纂しています。`
- **辞典の説明 (`bookDescription`)**:
  - `辞典の説明: {bookDescription}。`

### コンテキストの注入

ユーザーがチャット時に開いているMarkdownファイルの内容が、対話のコンテキストとして利用されます。

- **形式**:
  - `ユーザーは今「{context}」という単語のページを見ています。この文脈を踏まえて回答してください。`
- `{context}` には、アクティブなエディタの全文が挿入されます。

## Function Calling

AIは対話中に以下のツール（関数）を呼び出すことで、Obsidian内の情報にアクセスできます。

### 利用可能なツール

1.  **`getWordList()`**
    -   **説明**: 辞典に登録されているすべての単語の一覧を取得します。
    -   **引数**: なし
    -   **戻り値**: `{ words: string[] }` - 単語名の配列。
    -   **実装**: `geminiService.ts` 内の `getWordList`

2.  **`getWordDetail(word: string)`**
    -   **説明**: 指定された単語の詳細な説明（Markdownファイルの内容）を取得します。
    -   **引数**:
        -   `word` (string): 内容を取得したい単語名。
    -   **戻り値**: `string` - ファイルの内容。見つからない場合はその旨を伝えるメッセージ。
    -   **実装**: `geminiService.ts` 内の `getWordDetail`

### 処理フロー

1.  ユーザーからの入力を受け取ります。
2.  AIはプロンプトとユーザー入力に基づき、テキストを生成するか、または必要な情報を得るために上記ツールのいずれかを呼び出すかを判断します。
3.  ツール呼び出しが要求された場合（`functionCall`）、システムは対応する関数を実行します。
4.  関数の実行結果（`functionResponse`）を対話履歴に追加し、再度AIに処理を渡します。
5.  AIは関数の結果を踏まえて、最終的な応答テキストを生成します。
6.  このプロセスは、AIがテキストの応答を返すまで繰り返されます。

この仕組みにより、AIは「辞典にどんな単語がある？」「〇〇について教えて」といった質問に対して、実際のファイル内容に基づいた正確な回答を生成できます。
