# UI改善計画

## AIチャット画面の改善

### 概要

AIチャットの利便性を向上させるため、以下の機能を追加・改善する。

### 計画

1.  **チャット内容のコピー機能追加**
    *   **目的**: ユーザーがAIや自身の発言を簡単に再利用できるようにする。
    *   **実装方針**:
        *   各メッセージ（ユーザー、AI双方）に「コピー」ボタンを設置する。
        *   ボタンはメッセージの右上に配置し、マウスホバー時にのみ表示されるようにして、UIの簡潔さを保つ。
        *   ボタンクリックで、該当メッセージのテキストコンテンツをクリップボードにコピーする。
        *   コピー完了後、ユーザーに「メッセージをコピーしました」といったフィードバックを通知（`new Notice`）する。
    *   **対象ファイル**:
        *   `src/ui/ChatView.ts`: UI要素の追加とクリップボードへのコピー処理を実装。
        *   `styles.css`: コピーボタンの表示・非表示やスタイルを定義。
